피커에서 폴더를 고르면 그 하위 파일과 고른 뒤에 추가되는 파일까지 접근되는가 — 구글 문서에 답이 없어서 직접 잰다. 이 답에 따라 Readmon의 Google Drive 연동 설계가 갈린다.

0. 준비물

Google Cloud Console에서 웹 애플리케이션 OAuth 클라이언트와 API 키를 만든다. iOS 클라이언트로는 브라우저 JS가 동작하지 않는다.

  1. 클라이언트 ▸ 클라이언트 만들기 ▸ 웹 애플리케이션. 승인된 JavaScript 출처에 이 페이지의 출처를 넣는다: …
  2. 사용자 인증 정보 ▸ API 키를 하나 만든다. (Picker API가 이 키를 요구한다)
  3. API 및 서비스 ▸ 라이브러리에서 Google Picker API와 Google Drive API를 사용 설정한다.
  4. 프로젝트 번호는 Cloud Console 대시보드에 있다(숫자만).

이 값들은 이 브라우저에만 저장된다(localStorage). 서버로 전송되지 않는다.
